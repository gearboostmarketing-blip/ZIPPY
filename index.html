How it works
  1. 1Bring it in. Import the chat, paste lines or sync phones. Each line lands in its month; nothing is cleared.
  2. 2Check the Log. Fix yellow rows and set each line’s type and currency.
  3. 3Books. The month in US dollars, carried from last month, with the safe counts.
  4. 4Receipts. One official receipt per expense, saved as PDFs.
  5. 5Reports. Export the month, or send it straight to Zoho.
