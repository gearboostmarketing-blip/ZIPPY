How it works

1. Import the log. 2. Check the Log tab: fix anything highlighted yellow, set each line's type (expense, advance, salary, money in, safe count, or skip) and currency. 3. Books gives you money in / money out per currency to compare with your records. 4. Receipts builds one official receipt per expense; fill in the missing details, mark each reviewed, then print or save as PDF.
